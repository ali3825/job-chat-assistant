# Demo script (about 4 minutes)
1. Open the app; point out the "basic mode" banner (no LLM key needed).
2. Upload a PDF/DOCX resume (progress bar) -> review the extracted profile; inferred fields are tagged.
3. Click "Edit details" or type "add skill Docker" / "I have 3 years of experience" -> profile updates.
4. Say "looks good" -> ranked recommendations with scores, matched/missing skills and explanations.
5. Follow-ups: "Show me remote jobs", "Only show jobs requiring React", "Show jobs with at least 80% match", "Find entry-level jobs suitable for my resume", "Explain why job 3 matches my profile".
6. "Apply to job 3" -> confirmation naming the job -> "Yes". Point out the honest wording: saved here, NOT submitted; use the official link.
7. "Apply to job 3" again -> duplicate prevented.
8. "Show my applied jobs", "What is my application status?", "How many jobs have I applied to?", "Mark job 3 as applied".
9. Restart the server; applications persist, chat memory does not (by design).
